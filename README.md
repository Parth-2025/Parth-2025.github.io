# Parth Mohan portfolio

React + TypeScript, built with Vite. The opening uses the React Bits particle title. Project pages include real product walkthroughs, a scroll-drawn process path, technical notes, and Motion disclosures. Scrolling between sections does not animate floating project-title letters.

## Local development

Run `npm ci`, then `npm run dev`. Run `npm run build` for the production build and `npm run preview` to inspect it.

## GitHub Pages

The deployment workflow builds `dist` and deploys it on pushes to `main` or `master`. This account-level Pages repository deploys at `https://parth-2025.github.io/`. Configure the repository's Pages source as **GitHub Actions** before publishing.

## Content and evidence

Project content comes from the previous portfolio. Bite Right's 95% is explicitly labeled as a local usage/test-case result, with no invented sample size. Aptean's 300-to-30-hour result preserves the original account and should receive a more precise measurement description when available. Coach Connect's audience is not described as active users.
