# parthmohan

Personal website for Parth Mohan — a single static `index.html` (no build step) served via GitHub Pages.

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy (GitHub Pages)

1. Push this repo to `https://github.com/Parth-2025/parthmohan`.
2. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Site publishes at `https://parth-2025.github.io/parthmohan/`.
